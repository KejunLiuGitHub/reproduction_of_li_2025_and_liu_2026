# Reuse and attribution

These materials are provided for inspection and research reproduction of the calculations described in this repository. The original author dataset remains at Zenodo; cite Li et al. and DOI 10.5281/zenodo.15253851 when using its geometries. Exported and water-rotated coordinates should be identified as derived preparations.

No blanket license is assigned here to third-party data or software. CP2K, PLUMED and the author dataset retain their own terms. A general redistribution license for the project's original code and outputs has not been specified; contact the repository maintainer for uses beyond this reproduction package.
